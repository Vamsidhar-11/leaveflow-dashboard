# LeaveFlow – Employee Leave Management Dashboard

A clickable SaaS dashboard prototype for managing employee leave, built with AI-assisted prototyping (Claude Code).

**Live demo:** _add your Vercel link here_

## Features

**HR view**
- KPI cards: on leave today, pending approvals, days approved, average approval time
- Leave requests table with search, status filter and one-click Approve / Reject
- "Who's off this week" team calendar
- Leave taken by type and department availability charts

**Employee view**
- Leave balance cards (Casual, Sick, Earned)
- Apply-for-leave form with working-day calculation and balance check
- My requests with live status

Responsive on mobile, supports dark mode. Uses sample data.

## Tech
Single-page HTML, CSS and vanilla JavaScript. No build step.
